# ESTELART Platform

Plataforma e-commerce modular para catálogo, clientes, pedidos, combos, promociones, métricas, reportes automáticos y futura integración con asistente IA.

## Stack principal

- Frontend: React + TypeScript + Vite + Tailwind + pnpm
- Backend principal: Django + Django REST Framework
- Base de datos: PostgreSQL
- Testing backend: Pytest + pytest-django + Coverage
- Calidad backend: Pylint + Black + Mypy
- Testing frontend: Vitest + React Testing Library
- Infraestructura: Docker + Docker Compose
- CI/CD: GitHub Actions
- Microservicio futuro: FastAPI para IA y recomendaciones
